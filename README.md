# Employee Attrition Prediction

A machine-learning project that predicts employee attrition using the **IBM HR Analytics Employee Attrition Dataset**. The project was completed as part of the **Persevex Data Analyst Online Internship Programme** and applies classification models to a practical HR analytics problem.

## Project Objective

Employee turnover can increase recruitment costs, training expenses, and productivity losses. This project develops a data-driven approach to identify employees who may be at higher risk of leaving, allowing HR teams to consider proactive retention strategies.

## Dataset

**IBM HR Analytics Employee Attrition Dataset**

The dataset contains employee-level information including age, job role, monthly income, overtime, business travel, distance from home, total working years, years at company, job satisfaction, and the target variable **Attrition**.

## Methodology

1. Loaded and inspected the employee dataset
2. Checked data quality and missing values
3. Removed non-informative identifier/constant variables
4. Encoded categorical variables using Label Encoding
5. Separated predictors and the target variable (`Attrition`)
6. Split the data into training and testing sets (80:20)
7. Built three classification models:
   - Logistic Regression
   - Decision Tree
   - Random Forest
8. Evaluated model accuracy and classification performance
9. Analysed feature importance using Random Forest
10. Saved and reloaded the Logistic Regression model using Pickle
11. Demonstrated a sample employee prediction

## Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | **88.44%** |
| Decision Tree | 79.93% |
| Random Forest | 88.10% |

Logistic Regression achieved the highest test-set accuracy among the three implemented models in this project.

## Key Findings

The project’s feature-importance analysis highlighted variables such as **Monthly Income, Overtime, Age, Daily Rate, and Total Working Years** among the important factors associated with attrition prediction.

The analysis also indicates patterns relevant to HR retention decisions, including the relationship of compensation, overtime, age, tenure, and commuting-related variables with employee attrition.

> Note: Feature importance and model accuracy indicate predictive associations in this dataset; they should not be interpreted as causal effects.
